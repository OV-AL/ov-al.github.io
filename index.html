Oval

Declare your bounded contexts. Oval generates a typed, composable effects surface at compile time — no runtime reflection, no boilerplate.
Get startedView on GitHub

Oval is a compile-time source-generator framework for .NET. You model a bounded context with ordinary C# types and apply Oval’s attributes; Oval emits a strongly-typed effects surface you compose with LINQ. Everything resolves while the compiler runs, so there is no runtime reflection and no hand-written plumbing to keep in sync — and the generated code is plain C# you can read.

Why Oval

Section titled “Why Oval”

Compile-time, not reflection

Section titled “Compile-time, not reflection”

Oval resolves data access, dispatch, and wiring while the compiler runs. There is no runtime scan and nothing to warm up — if it builds, the surface is correct.

Effects you compose with LINQ

Section titled “Effects you compose with LINQ”

Every attribute you apply produces a typed effect you combine with ordinary query syntax. Reads, writes, jobs, and events sit in one composable surface instead of scattered service interfaces.

Modules and platforms, not a monolith

Section titled “Modules and platforms, not a monolith”

Pick only the modules a context needs, and back each with a platform like Entity Framework, Postgres, or Redis. Swapping a backing store is a registration change, not a rewrite.

Generated code you can read

Section titled “Generated code you can read”

Oval emits clean, conventional C#, not an opaque trick. You can open the generated files, step into them, and review exactly what runs.
