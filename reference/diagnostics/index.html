Diagnostics

Oval’s analyzers report structural problems at build time, each with a stable identifier you will see in your build output. This page is the single place those identifiers are listed, grouped by the area that raises them, with a one-line description and fix for each.

Dispatch

Section titled “Dispatch”
ID Reports Fix
OVDSP01 A command lifecycle hook has an invalid signature and never fires. Make it static, take (TCommand, CommandContext), return Eff<RT, Unit>.
OVDSP02 A lifecycle hook targets a command that has no handler. Point the hook at a command that has a [CommandHandler].
OVCAP03 A handler’s runtime type is not a [BoundedContext] class. Return Eff over a [BoundedContext] class.
OVCAP02 Two referenced capabilities declare the same effects-section name, which would collide. Rename one module’s effects section, or set a distinct EffectsSection.

Authorization & security

Section titled “Authorization & security”
ID Reports Fix
OVAUTH01 A dispatch handler declares no authorization decision. Add [Authorize], [AllowAnonymous], or [SystemOnly].
OVAUTH02 A JWT validator never checks the revocation store, so it accepts revoked tokens. Call IRevocationStore.IsRevokedAsync and fail closed.
OVAUTH03 A dispatch handler declares more than one authorization decision. Keep exactly one of [Authorize], [AllowAnonymous], or [SystemOnly].
OVSEC01 A [DevelopmentOnly] type implements a DI contributor and could reach production. Remove [DevelopmentOnly], or move it to a test-only contributor.
OVSEC02 A DI contributor’s assembly is not in the trust lockfile. Add the trusted assembly to oval.contributors.lock.
OVSEC09 A connection string is read without Secret wrapping, escaping redaction. Pass the read to Secret.FromConfigBinder or Secret.From.
OVSEC11 A secret-named [ConfigSection] property is a plain string. Change the property to Secret<string>.
OVDBI01 Database isolation is enforced but the build uses a provider without row-level security. Use the PostgreSQL platform, or drop the isolation enforcement.

Configuration

Section titled “Configuration”
ID Reports Fix
OVCFG02 A connection-fallback declaration is incomplete or wrongly typed. Make it a Secret<string> naming a sibling connection-name property.
OVCFG03 A Config<T>() type argument is not a [ConfigSection], so it binds defaults silently. Mark the type [ConfigSection] (or register it).

Idempotency, resilience & ids

Section titled “Idempotency, resilience & ids”
ID Reports Fix
OVIDEM01 [Idempotent] sits on a read-only query handler. Move [Idempotent] to a [CommandHandler].
OVIDEM02 [Idempotent] without a key relies on the request header and fails off-HTTP. Set Key = nameof(Command.Field) for a server-derived key.
OVRES01 [Resilient] is missing a policy name or is not on a dispatch handler. Put [Resilient("policy")] on a handler with a valid policy.
OVTID01 A typed id is minted with its static factory inside a handler, bypassing the deterministic seam. Mint with the NewId<TId>() effect.
OVSTUB01 A [Stubbable] member (generic or by-ref) cannot be stubbed and gets a throwing default. Avoid generic/by-ref members, or accept the throwing default.

DataStore

Section titled “DataStore”
ID Reports Fix
OVDS01 A DataStore facet (such as [Owned] or [TenantScoped]) is on a non-[StoredEntity] type. Add [StoredEntity], or remove the facet.

Jobs

Section titled “Jobs”
ID Reports Fix
OVJOB01 A job handler resolves the ambient current user, which jobs do not have. Resolve IJobContext and use its identity.
OVJOBS01 A job handler has no bounded context that activates jobs to host it. Add a context with [Uses<Jobs>].
OVJOBS02 A job handler does not take exactly one job payload. Give it a single [BackgroundJob] parameter.
OVJOBS03 A job payload has more than one handler. Keep exactly one handler per payload.
OVJOBS04 A job handler is not a static effect over its bounded context. Make it a static method returning Eff<BC, Unit>.
OVJOBS05 A recurring job has an invalid cron expression. Use a standard 5-field cron expression (e.g. 0 9 * * 1-5).
OVJOBS06 A recurring job’s payload is not parameterless. Give the [BackgroundJob(Cron = …)] payload a parameterless constructor.
OVJOBS07 TimeZone is set without Cron. Add a Cron schedule, or remove TimeZone.

Events

Section titled “Events”
ID Reports Fix
OVEVT01 An event handler does not take exactly one event payload. Give it a single [Event<…>] parameter.
OVEVT02 An event handler is not a static effect over its bounded context. Make it a static method returning Eff<BC, Unit>.
OVEVT03 An event handler’s context does not use the event’s module, so events are not delivered. Add [Uses<TEventModule>] to the context.
OVEVT04 An event’s module type is not marked [EventModule]. Mark the module type [EventModule].
OVEVT05 An event module’s effects section is shadowed by a same-named top-level type. Set a distinct [EventModule(EffectsSection = "…")], or qualify the call.

HTTP clients

Section titled “HTTP clients”
ID Reports Fix
OVHTTP01 An [HttpClient] type is not partial, so no operations generate. Declare the type partial.
OVHTTP02 An [HttpClient<T>] config type is not a [ConfigSection], so nothing binds it. Annotate the config type [ConfigSection].
OVHTTP03 An [HttpClient] declares more than one auth attribute. Keep only one of [BearerAuth] or [BasicAuth].
OVHTTP04 An operation binds both [Body] and [Form] for one request. Use only [Body] or only [Form].
OVHTTP05 An [OAuthBacked<T>] client does not reference an [OAuthProvider] or adds extra auth. Point T at an [OAuthProvider] and remove other auth attributes.

OAuth

Section titled “OAuth”
ID Reports Fix
OVOA01 An [OAuthProvider] does not expose Secret<string> client id and secret. Declare both as Secret<string> properties.
OVOA02 An [OAuthProvider] class is not a [ConfigSection], so credentials do not bind. Also annotate it [ConfigSection].
OVOA03 An OAuth refresh mapper has the wrong signature. Make it static (OAuthRefreshResponse, OAuthTokenEnvelope) returning OAuthTokenEnvelope.
OVOA04 A provider that rotates refresh tokens has no refresh mapper. Add an [OAuthRefreshOperation] mapper, or rely on standard mapping.
OVOA05 An [OAuthBacked<T>] does not reference an [OAuthProvider] or has an empty connection id. Reference a declared provider with a non-empty connection id.
OVOA06 An [OAuthProvider] declares no revoke URL, so revoke is local-only. Declare a revoke URL to revoke upstream too, or accept local-only.
OVST01 A state-transition handler is not static or takes the wrong parameter. Make it static with a single StateTransition<TFrom, TTo> parameter.
OVST02 A state-transition handler does not return the effect type. Return Eff<TRuntime, Unit>.
OVST03 Multiple handlers cover the same transition and all run. Remove the duplicate, or split into separate handler classes.

Identity

Section titled “Identity”
ID Reports Fix
OVID01 An identity user type has no string Email property, so email login fails. Add a string Email property.
OVID02 A [ClaimsEnricher] method has an invalid signature. Make it static and return EnrichedClaims with the expected parameters.
OVID04 An identity user type is not a [StoredEntity], so registrations cannot persist. Add [StoredEntity] to the user type.
OVAUTH04 A switch over the Google verification result is not exhaustive and could throw. Add the missing arms, or a fail-closed default.
OVAUTH05 A credential-failure response carries a detail that leaks which check failed. Drop the detail; use the uniform invalid-credentials response.
OVAUTH06 A Google success path does not check that the email is verified. Gate on EmailVerified before issuing tokens.
OVAUTH07 A handler maps under the reserved /auth/* prefix owned by generated endpoints. Move the handler to a different route prefix.
OVSEC10 A Google client secret is read without Secret wrapping. Bind it via [ConfigSection] + Secret<T>.

Payments

Section titled “Payments”
ID Reports Fix
OVPAY01 A Stripe event translator has the wrong shape. Make it public static, take one event, return a nullable domain record.
OVPAY02 Two translators handle the same Stripe event type in one class. Keep one translator per event type.
OVPAY03 A Stripe client binds a raw card-data field, breaking PCI scope. Use Checkout Sessions or client-side tokenization.
OVPAY04 A Stripe webhook endpoint has no signature validator registered. Register a validator (HMAC, or the development stub).
OVPAY05 A resilient handler retries a Stripe write with no idempotency key. Supply an idempotency key to avoid duplicate charges.

REST

Section titled “REST”
ID Reports Fix
OVREST01 A [RouteBind] token has no matching segment in the route template. Add the {token} segment to the template.
OVREST02 A [SystemOnly] handler also carries an HTTP-verb attribute. Remove the HTTP verb so the handler stays internal.
OVREST03 A webhook handler is missing [AllowAnonymous] and/or [TenantOptional]. Add both attributes.
OVREST04 A route template token has no input property to bind it. Name a property after it, or add [RouteBind("token")].
OVREST05 A webhook secret resolver method has an invalid signature. Make it static, take the request context, return the resolution effect.
OVREST06 A webhook envelope is reused as a plain dispatch input, skipping signature checks. Split the transport envelope from the domain command.
OVREST07 An [Affordance] sits on a [SystemOnly] command, which can never be a user action. Remove [SystemOnly] or [Affordance].
OVREST08 A declared webhook secret resolver was discovered but not wired. Resolve the runtime mismatch so it wires.
OVREST09 An affordance key or link token does not resolve to an entity property. Name public entity properties; ensure the entity has an Id.
OVREST10 An affordance owner reference names no public entity property. Set it to a public property holding the owner’s user id.

Screens

Section titled “Screens”
ID Reports Fix
OVSCRN01 A screen’s backing type is not a registered handler input. Reference a command or query handler input record.
OVSCRN07 A screen’s kind does not match its handler kind. Use a query for list/detail screens, a command for create/form.
OVSCRN08 Two screens declare the same route. Give each screen a distinct route.
OVSCRN09 A screen class has no Configure method. Declare a static void Configure(…) method.
OVSCRN10 An unsupported construct appears in a screen’s Configure body. Keep screen configuration declarative — no locals, loops, or calls.
OVSCRN11 A field or column selector is not a simple property access. Use a t => t.Property selector.

Server-Sent Events

Section titled “Server-Sent Events”
ID Reports Fix
OVSSE01 An [SseApi] route prefix collides with the REST prefix. Set a distinct [SseApi(RoutePrefix = "…")].
OVSSE02 Two streams declare the same path. Give each stream a unique path.

Slack

Section titled “Slack”
ID Reports Fix
OVSLK01 A Slack client is declared but the Slack runtime is not referenced, so API errors are not raised. Reference Oval.Slack.

CSV

Section titled “CSV”
ID Reports Fix
OVCSV01 A [CsvRecord] type is not partial. Declare the type partial.
OVCSV02 A CSV field attribute sits on a non-[CsvRecord] type and is ignored. Mark the containing type [CsvRecord].
OVCSV03 A CSV field’s type is not string, parseable, or an enum, and has no converter. Add [CsvConverter(typeof(…))].
OVCSV04 Two fields resolve to the same column name. Rename a field, or set distinct [CsvField] overrides.
OVCSV05 A converter type does not implement the converter contract. Reference a type implementing ICsvConverter<TField>.
